# Hospital Management System Database

## Overview
A portfolio-ready MySQL database project for learning SQL and Database Administration.

## Features
- Normalized relational schema
- Primary and Foreign Keys
- Sample data
- Common SQL queries

## Tables
- departments
- doctors
- patients
- appointments

## Technologies
- MySQL
- MySQL Workbench
- SQL

## How to Use
1. Run `schema.sql`
2. Run `sample_data.sql`
3. Execute queries from `queries.sql`

## Skills Demonstrated
- Database Design
- SQL Joins
- Data Integrity
- Relational Modeling
